# Pixel art web (PyArena)

Original retro pixel-art identity. Inspired by the *genre* of 8/16-bit adventure and arcade games, never by a specific game: no names, characters, logos, fonts, palettes or iconic visuals of existing games.

## 1. Project constraints (non-negotiable)
- Plain HTML + native ES modules, **no framework, no JS build**. Tailwind v4 compiled by the standalone binary inside Docker from `frontend/styles/app.css`.
- **CSP:** `script-src 'self'`, `style-src 'self'`. No inline `<script>`, no `style="…"` attributes in HTML, no `<style>` tags. Setting `el.style.x` / CSS variables from JS is fine (CSSOM).
- **Never `innerHTML`/`outerHTML`/`insertAdjacentHTML`** with any data. Build DOM with `components/dom.js` (`el()`), `textContent`.
- Every visible string goes through i18n (`t()` / `data-i18n`), PT-PT + EN.
- Mobile first (360 px), tap targets ≥ 44 px, nothing hover-only, `100dvh`, safe areas.
- Colours only from theme tokens (`--c-*`, Tailwind `bg-surface`, `text-accent`, …), never fixed Tailwind colours. All 6 themes (floresta, masmorra, oceano, deserto, neve, noite) must look right. The light themes (deserto, neve) are the hardest for contrast: check them.

## 2. Visual language
- **Grid:** design on a 4 px grid; borders 2–4 px; no border-radius anywhere (`0px`).
- **Borders and depth:** hard stepped `box-shadow` frames (`--frame`, `--pixel-shadow`), inner highlight on top (`inset 0 3px 0 var(--hi)`) and shade at the bottom (`inset 0 -4px 0 var(--lo)`). No blur and no soft shadows.
- **Type:** `font-pixel` (Press Start 2P) only for titles, numbers, buttons and badges (it's wide: short labels). `font-ui` (Pixelify Sans) for UI copy. `font-mono` for code and problem statements (readability first).
- **Texture:** dither and scanline PNG tiles (`assets/sprites/ui/`), `image-rendering: pixelated` on every raster image and canvas.
- **Sprites:** 16/32/64 px PNGs generated by `frontend/assets/gen_assets.py` (Pillow in a throwaway container). Add new sprites there, never hand-edit PNGs.
- **Medals:** 1st gold, 2nd **bronze**, 3rd **copper** (`components/medal.js`), shown above avatars in every top-3 view.
- **Hierarchy:** one hero per screen, generous spacing, chunky primary action, secondary actions as `btn-pixel--ghost`.

## 3. Motion
- CSS: `steps(n)` keyframes (frame-by-frame look), 2 px press-down on `:active`, no `transition: all .3s ease`.
- Rich choreography (entrances, counters, list reordering, celebrations): use the **gsap** skill with stepped eases.
- Everything must respect `prefers-reduced-motion` (static fallback, no essential info only in motion).

## 4. Three.js pixel scenes
- Scenes live only in `frontend/scenes/`, loaded with dynamic `import()` after first paint (`whenIdle`), **never on the editor page**.
- Use `scene-base.js`: low internal resolution (~320×180) upscaled with `NearestFilter`, DPR capped, 30 fps for background scenes, pause on `visibilitychange`, `dispose()` on unmount, auto-degrade to the 2D poster if frame time > 33 ms for 2 s or WebGL is missing.
- Voxel models built from boxes, flat-shaded, palette from the active theme (`scenes/themes.js`). Text and labels are HTML overlays, never 3D text.

## 5. Performance budget
Own JS < 50 KB gzip per page (excluding three.js / CodeMirror / GSAP). CSS < 20 KB gzip. No layout shift when canvases or images appear (reserve the space). Fonts subset + `font-display: swap`.

## 6. Checklist before reporting done
- Screenshots at 375×812 and 1280×800 in at least one dark and one light theme.
- Console clean, no CSP violations, `check_i18n` 0 errors, `pytest` (it includes a no-innerHTML guard).
- Reduced-motion and WebGL-off fallbacks still readable.

## 7. Refactoring Existing Landing Pages
When modifying or upgrading an existing web project to this pixel-art + 3D style:
- **Preserve Structure & Copy**: Keep existing layout hierarchy, semantic HTML, routing, and text content intact unless asked to change them.
- **Swap Modern CSS for Pixel Tokens**: Replace existing rounded cards (`border-radius`), soft shadows, and modern sans-serif fonts with pixel fonts, `0px` corners, hard `box-shadow` borders, and constrained palette variables.
- **Inject Non-Blocking 3D Canvas**: Mount the pixelated Three.js scene inside a fixed or absolute background wrapper (`z-index: 0`, `pointer-events: none` unless interactive) behind existing content containers (`z-index: 10`).
- **Convert Hover & Scroll Animations**: Replace smooth CSS transitions (`transition: all 0.3s ease`) on existing buttons and cards with `steps()` keyframes and `2px` active press offsets.
